# Part II · The Python Toolkit

> Every `str` and `list` method, the built-ins and standard library you'll use, and what you must be able to hand-write

## What this part contains

A **reference** part. Every public `str` and `list` method, the built-in functions that matter for DSA, and the standard-library modules (`collections`, `heapq`, `bisect`, `itertools`, `functools`, `math`), each with cost, version notes and pitfalls. Chapter 9 maps every tool to a tier: use freely, know how, or hand-write.

## When to read it

Skim it once, then come back to look things up. Read Chapter 9 fully: it tells you which built-ins interviewers take away.
