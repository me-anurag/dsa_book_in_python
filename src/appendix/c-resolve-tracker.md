# Appendix C: Re-solve Tracker

The front matter's schedule (0.4): re-solve each problem from a blank file on day 1,
day 3, day 7 and day 21 after you first solve it. Write the date in each column as
you pass it. If a re-solve fails, restart that problem at day 1.

Passing means: correct, without notes or hints, and you can state the time and
auxiliary complexity with reasons. By day 7, it should also take noticeably less
time than your first solve.
