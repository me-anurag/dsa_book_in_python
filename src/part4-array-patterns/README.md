# Part IV · Array Patterns

> Eleven array techniques, from in-place edits and hashing to binary search, Kadane and monotonic stacks

## What this part contains

The core of the book for arrays. Each chapter teaches one pattern with recognition signals, a reusable template, its invariant, a dry run, and 3–5 worked problems that go brute force → optimal, followed by a practice set.

## When to read it

Work through it in order: later chapters build on earlier ones. Do every practice set before moving on.
