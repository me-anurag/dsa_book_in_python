# Part III · Complexity & Performance

> How to reason about complexity, how fast CPython really is, and the cost of every common operation

## What this part contains

How to derive time and space complexity (including loops that look quadratic but aren't), how to turn constraints into a target complexity using a **measured** Python speed budget, why CPython is slow and how to work with that, and a printable cheat sheet of operation costs.

## When to read it

Read Chapter 10 before the pattern parts; it tells you which approach can pass before you write it.
