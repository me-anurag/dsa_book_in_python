# Part V · String Patterns

> String fundamentals, hashing on strings, palindromes, string windows, parsing with stacks, and string matching

## What this part contains

The same chapter format as Part IV, applied to strings: character arithmetic and tokenizing, signatures and rolling hashes, palindromes, the need/have window technique, parsers and digit arithmetic, and KMP / Z / Rabin–Karp matching.

## When to read it

Read it after Part IV. Several chapters reuse array patterns (windows, two pointers, hashing) on characters.
